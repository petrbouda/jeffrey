Backup & Reset

Moves everything in your current home folder into <home>/backups/upgrade-<timestamp>/ and starts Jeffrey fresh. Nothing is deleted — recordings can be re-imported from the backup folder at any time.

Use a different home folder

Keeps the current home folder untouched and points Jeffrey at a new, empty home folder instead.

The choice is remembered in jeffrey-home.redirect inside the current home folder, so future starts use the new location automatically.
