# Microscope MCP Phase 4 Implementation Plan

> Execute independent workflow tasks with parallel agents; root integrates wiring, diagnostics and serial verification.

**Goal:** Add bounded remote investigation, recoverable operation controls, reproducible evidence and quality diagnostics.

**Architecture:** Add tools and resources to existing families/providers. Reuse replay RPCs, profile contexts, existing background jobs and pipeline tracking. Preserve text wrappers and expose typed objects on supported protocol versions.

**Tech stack:** Java 25, Spring, gRPC/protobuf, existing Jackson, Vue documentation.

**Spec:** `docs/superpowers/specs/2026-09-12-mcp-phase4-design.md` (approved Phase 4 audit scope).

## Constraints

- No commit/push/PR until requested for this change set.
- Existing tools remain compatible; Hub/IDE access gates and family filtering remain effective.
- No protocol task transport, infinite stream, new database migration or unrelated scheduler.
- Root runs Maven serially. Each lane writes regression tests first and requests its RED run before implementation.

## Tasks

- [x] Replay: add a standalone Hub replay tool and bounded collector; additive scoped replay request/coverage response; scoped persistence lookup; tests for full identity, row/byte bounds, deadline/cancellation, corrupt input and old-client compatibility. Own replay client/service/proto/persistence files and standalone tool/tests; root owns assembler wiring.
- [x] Jobs: add attempt-aware operation adapters and status/cancel tools; retain worker ownership until exit in BoundedJobs and PipelineRunRegistry; expose import/download/heap operation identities with progress and retry rules. Tests use latches to exercise cancellation before start, during work, ignored interrupts, completion races and stale IDs. Own job tools/registries/services/tests; root owns shared wiring.
- [x] Evidence/quality: add profile evidence tool and URI template through existing McpFinding/resources; extend comparison quality using stored recording evidence. Tests use hand-derived fixtures for identity, units/denominators, incompatible configuration, missing evidence and bounded output. Own evidence/comparison tools/models/tests; send resource/wiring requirements to root.
- [x] Diagnostics/integration: add fixed-cardinality endpoint metrics and safe dynamic diagnostic resource, readiness counts and bounded Hub probes; wire new tools into appropriate presets and family gates; endpoint tests verify advertised tool results/resources, cancellation hints and hidden-family behavior.
- [x] Documentation/verification: update MCP and replay gRPC docs. Run affected MCP, replay, pipeline and manager reactor tests plus documentation type-check; review full diff and verify original edits unchanged.

## Validation command

Use Java 25 and Maven `-Dexec.skip=true`, with `-am -Dsurefire.failIfNoSpecifiedTests=false`. Run focused RED/GREEN tests per lane, then one integrated affected suite. The worktree baseline uses `McpCatalogueIntegrationTest,McpStructuredResultTest,BoundedJobsTest,PipelineRunRegistryTest`.
