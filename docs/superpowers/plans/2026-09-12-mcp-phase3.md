# Microscope MCP Phase 3 Implementation Plan

> Execute the approved Phase 3 scope in bounded tasks, using parallel agents for independent catalogues and configuration. Root owns protocol integration and serial Maven validation.

**Goal:** Make discovery complete and pageable, expose typed results incrementally, and let clients identify the build and select a smaller tool catalogue.

**Architecture:** Existing tools and Markdown remain available. Selected catalogue methods return a typed text-plus-object result with declared JSON output schemas. Stateless keyset cursors bind to normalized filters; Hub scans remain cancellable live reads and report incomplete scopes separately from page limits.

**Tech stack:** Java 25, existing Jackson and MCP reflection, Spring configuration, Vue documentation.

**Spec:** Approved Phase 3 audit findings F11, structured results, family presets, actual version/safe capabilities, and stale workflow guidance (conversation audit dated 2026-09-12).

## Constraints
- Preserve all existing tool names and text callers; default advertises all families.
- Add no runtime dependency, new endpoint, database migration, authentication or Phase 4 workflow.
- Keep original checkout and its four uncommitted test edits untouched.
- Root runs Maven serially; agents write failing tests before implementation and request the RED run.

## Tasks
- [x] Protocol: introduce `McpToolResult(String text, ObjectNode structuredContent)` and `@McpOutputSchema(String value)`; pass typed results through reflective/scoped/composite providers. Advertise schema and structuredContent for supported revisions from 2025-06-18 onward, keeping text compatibility for older revisions. Reject invalid schemas at assembly and oversized structured results as explicit tool failures. Use the actual Jeffrey version for initialization and expose the supported protocol list from one source.
- [x] Profiles: add optional cursor to profiles_list, retain String two-argument wrapper, stable profileId ordering, normalized-search-bound keyset cursor, recordingId, returned/total/hasMore/nextCursor/complete fields. Bound complete rows and display scalars. Add profile resource cursor URI/template. Tests cover >1000 results, inserts before cursor, malformed/mismatched tokens, output caps and resource routing.
- [x] Hubs: add optional cursor to hubs_sessions, retain legacy String wrapper, stable timestamp/full-reference order, filter-bound cursor with fixed relative-time cutoff. Distinguish total from observedTotal after partial scans, expose failure scopes, retain Phase 2 cancellation. Tests cover ties, partial/empty pages, changed live rows, cutoff, per-project limits and output size.
- [x] Configuration: add all/jfr/heap/hub presets; explicit families override preset and existing access switches constrain them. Reject unknown settings. Add safe jeffrey://server resource with version, effective tool families/count, protocol versions and static capabilities. Measure default versus preset tools/list bytes. Refresh heap preparation guidance.
- [x] Integrate: endpoint tests for typed results, schema presence, legacy text, schema/result bounds, actual version and laziness; run affected MCP/tool reactor tests, documentation typecheck, diff review, verify original edits untouched.

Acceptance: a client can continue every bounded catalogue, distinguish complete from partial Hub coverage, consume structured results without guessing, obtain a narrower toolset explicitly, and identify the application build. Local work waiting for existing pipeline slots keeps the established Phase 2 state contract.
