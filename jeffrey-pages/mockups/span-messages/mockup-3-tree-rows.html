3Rows in the tree

Every message becomes a row of its own, indented one level under the span that emitted it and folded with it — the "span logs" reading. The severity and the title sit on the row, the Duration column becomes the offset, and the track carries a tick at the instant. The stable type did not fit in a 20rem name column, so it moved into the expansion. Shown with the CRITICAL alert expanded.

What it buys

  • Nothing is hidden: every message is on screen with its text, at trace scope, with no click.
  • Parentage is structural, not inferred — the indent is the span it belongs to.
  • The tree already folds. Collapsing a span takes its messages with it, which is the behaviour a reader expects.
  • This is what Jaeger and Zipkin do with span logs, so it needs no explaining.

What it costs

  • Six messages add six rows to a six-span trace. A chatty request doubles the waterfall, and the shape of the trace — the thing the waterfall exists to show — is what pays.
  • Ordering is honestly awkward: PAYMENT_RETRY at +158 ms is drawn after jdk.SocketRead, which was still running when it fired. Look at rows 8-10 above.
  • A zero-duration row in a duration chart is a category error — the Duration column has to change meaning to +offset for these rows.
  • The 20rem name column cannot hold indent, severity, title and the stable type. The type had to move into the expansion, so the row alone no longer identifies the message.
  • The run-collapsing machinery (5+ same-named siblings become one row) would have to learn about messages too, or a retry loop floods the tree.

What it takes to build

  • Touches the most load-bearing code of the five: displayRows, visibleSpans, traceTree.ts, fold state, run detection and the critical-path filter all assume a row is a span.
  • Either a discriminated union in displayRows ({run} | {span} | {message}) or synthetic span rows — and the latter re-opens exactly the mistake TraceScopeEvent avoids by not naming its field spanId.
  • Largest diff of the five, and the one most likely to regress the waterfall itself.
