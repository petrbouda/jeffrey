1Message lane

A lane of its own above the span rows, mirroring the pause lanes the waterfall already draws — but with diamonds instead of bands, because a message is an instant, not a stretch. Colour is severity, the label carries the mix and the count, and a click opens the message. Shown here with the CRITICAL alert open.

What it buys

  • Reuses the lane the waterfall already has — same grid, same label-meter-track shape as GC pause and Safepoint, so it needs no new visual vocabulary.
  • One glance answers "did anything shout during this request, and when" before any span is opened.
  • The lane sits outside the span rows, so folding, filtering and the critical-path toggle cannot hide a CRITICAL alert.
  • It scales: 200 messages are 200 marks on one rail, not 200 rows.

What it costs

  • The mark says when, never which span — the link between the two exists only in the popover, or as the row tint shown here.
  • Marks collide. Six are comfortable; twenty in one millisecond need clustering, and a cluster badge is a second design.
  • A popover inside a fullscreen modal is a third layer of surface. Escape now has three meanings.
  • Severity by hue reuses danger (already GC pause) and warning (already the critical-path marker).

What it takes to build

  • One .wf-lane block in TraceWaterfall.vue and a Messages overlay switch beside the three that exist.
  • A messages array on TraceDetail; positions come from the same traceWindow() the bars use.
  • The popover is the only genuinely new component. Smallest diff of the five.
