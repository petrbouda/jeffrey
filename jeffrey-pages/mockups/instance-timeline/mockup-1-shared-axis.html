1Shared-axis waterfall

The straight translation of the Trace modal's waterfall onto instances. One ruler at the top of the card, and every instance is a single row underneath it on the same grid the trace waterfall uses — 20rem 1fr 5.5rem: name gutter, shared track, right-aligned duration. Time runs left → right, oldest at the left edge, Now at the right. A row is ~28px instead of ~140px, so twenty instances fit where three used to. The instance that finished before the window opens is not an empty card any more — it is a dimmed ghost row with a ◀ earlier marker saying how far outside it sits, so it can still be clicked.
