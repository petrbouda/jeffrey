Tool catalogue

Families an agent can call. Every tool declares in its MCP annotations whether it reads or writes.

profiles_*

read

Find a profile, summarize it, fetch evidence, and a link back into the UI.

summary · features · evidence · viewLink

flamegraph_*

read

Stack-weighted exports for any event type, sliced by thread and time.

list · export

jvm_*

read

GC, safepoints, JIT, threads, NMT, container, flags, Auto Analysis.

gc · jit · safepoints · nmt · container

heap_*

read

Dominators, leak suspects, GC-root paths, class-loader leaks, OQL, diff.

getLeakSuspects · getPathToGCRoot · oql

jfr_* · SQL

read

DuckDB SQL over events, threads and stacks when no dashboard answers it.

executeQuery · queryEvents · describeEventType

traces_*

read

Slowest traces, span flamegraphs, attribute search.

slowestTraces · spanFlamegraphExport

sessions · files · download · fetchFile

ide_*

switchable

resolve · source · open · link
03

Skills & agents

The microscope plugin — the method on top of the tools.

skilluse whene.g.
profile-runNothing is recorded yet — record a benchmark, test or the app, then analyze."profile this benchmark"
analyze-jfrCPU, wall-clock, allocation, locks, GC, JIT, threads, native memory."where does the time go?"
analyze-heapWhat holds memory, what leaks, which class loader survived."why did we OOM?"
compare-jfrTwo profiles, differential flamegraphs."before vs. after"
regression-checkTwo revisions built and profiled the same way."did this PR regress?"
advise-jfrHot frames → source → minimal edits, verified by re-profiling."what should I change?"
analyze-hubRecordings, dumps and logs living on a Jeffrey Hub."why was prod slow?"
jfr-sql · heap-sqlDuckDB SQL when purpose-built tools don't answer."GC pauses > 50 ms per minute"
reportEvidence rules for any written finding."write it up"
agentsprofile-lead triages and dispatches profile-analyst and heap-triage, returning findings only."review this recording"

05

Guarantees

No model inside

Jeffrey never calls a model provider. The only AI is the agent you already run.

Read-only by declaration

100 of 111 tools only read; the eleven that write or reach out say so.

Off-switches

mcp.hubs.enabled and mcp.ide.enabled for the families that leave the process.
