Read Microscope docs

Your coding agent can read the profile, too.

Microscope's MCP server hands Claude Code, Codex and any MCP 2026-07-28 client the same analysis you see in the UI — next to your source code.

111 MCP tools

Profiles, flamegraphs, JVM dashboards, heap, traces and SQL — 100 of them strictly read-only.

10 skills

profile-run, analyze-jfr, analyze-heap, advise-jfr, regression-check and more.

3 sub-agents

profile-lead, profile-analyst and heap-triage return findings, not dumps.

No model inside

Jeffrey never calls a model provider — your agent calls in, your data stays local.

Install

Two commands in Claude Code

The MCP server is on by default at /api/mcp; the plugin adds skills and agents.

/plugin marketplace add petrbouda/jeffrey /plugin install microscope@jeffrey
