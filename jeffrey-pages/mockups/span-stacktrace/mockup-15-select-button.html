The pick, and one thing the move needs

1 — btn-outline-primary, adjacent. It is a real house variant rather than a scoped rule, it separates from Fold libraries and Copy by hue while matching them box for box, and it does not compete with the solid Fold libraries the way 3 does. 2 is the pick if you want the lighter ground specifically rather than a lighter outline — it needs one scoped rule, which is fine, but it is worth knowing it is not something the app already has.

The move is not purely cosmetic. The button belongs to the dock (TraceWaterfall) and the toolbar belongs to TraceStackTrace, so the stack component needs a slot for a leading action in .st-acts. That keeps the stack panel unaware of spans and selection — it just renders whatever the host puts there — and it is what makes the same panel work in the span detail, where there is no span to select and the slot is simply empty.

Deleting the offset costs nothing. +91ms 969us is the throw's offset into the trace; the row it opened from still shows it in the span detail list, so the header was repeating a number the reader had just clicked on.
