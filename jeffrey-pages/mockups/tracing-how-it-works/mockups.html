Tracing Pipeline Diagram

Five ways to replace the ASCII pipeline block on Jeffrey Tracing → How It Works with a rendered diagram, all built from the same palette and chip vocabulary as DocsArchDiagram.vue. Same content in every variant — application, one JFR recording, Microscope — so the comparison is only about how the mechanism reads.

The diagram surfaces stay light in dark mode on purpose: they preview a light docs page. Icons here are hand-drawn stand-ins for the bi bi-* glyphs the real component uses.
