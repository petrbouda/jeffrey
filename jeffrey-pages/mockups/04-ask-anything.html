Connect

Pick your agent.

The MCP server is on by default at /api/mcp. The plugin adds the skills and agents.

Claude Code

Runs on Claude Code's v2 MCP runtime — the default on v2.1.274+ in many setups; elsewhere start it with MCP_SDK_GENERATION=v2.

/plugin marketplace add petrbouda/jeffrey
/plugin install microscope@jeffrey

Codex

v0.147.0 or later with the opt-in protocol flag turned on globally.

# ~/.codex/config.toml
[features]
mcp_2026_07_28 = true

codex plugin marketplace add petrbouda/jeffrey

Gemini CLI

The extension installs today and connects once Gemini CLI supports MCP 2026-07-28.

git clone https://github.com/petrbouda/jeffrey
gemini extensions install ./jeffrey/jeffrey-claude-plugin
