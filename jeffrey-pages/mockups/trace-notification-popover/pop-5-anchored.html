5Anchored card — a caret, and no magic number

The popover's placement is currently transform: translateX(-70%) — a magic number that guesses which side of the mark has room, and guesses wrong near either edge. This makes it a proper tooltip instead: a caret that points at the diamond, so the panel is free to sit wherever it fits, and placement clamped to the card's own bounds rather than offset by a fixed fraction. Same header band as direction 1.

Width is also content-sized (min 22rem, max 30rem) — but measure the two panels below and they come out the same 480px, both pinned to the 30rem cap. That is worth knowing before picking this one: a single profileId attribute is a 36-character UUID, and one unwrapped chip that wide pushes max-content past the cap whatever the message says. So content-sizing buys almost nothing here — what this direction is actually worth is the caret and the clamping, which fix a real placement bug near either edge.
