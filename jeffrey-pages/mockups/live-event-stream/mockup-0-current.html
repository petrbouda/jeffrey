Baseline — what is on master today. The pre-existing flat event list, extended in place rather than redesigned. Styles here are copied verbatim from WorkspaceEventLog.vue and design-tokens.css, so this is what the five alternatives are competing against.

What the streaming work changed here

  • The Live badge in the toolbar — the only new visual element. It also renders Connecting…, Reconnecting… and Paused.
  • Four new event types with their own badge colour, icon and description: recording file, artifact file, instance finished, instance expired.
  • File events surface fileName / fileType / sessionId / size as content pairs.
  • Arriving events prepend into the list, de-duplicated by event id and capped so a long-lived tab cannot grow without bound.

What it still does not do

  • No visual cue that an event just arrived — new rows simply appear.
  • No grouping by session, and no view of the chunk currently being written.
  • No "N new since you looked" counter, and the resume offset is never surfaced.
