Jeffrey Traces Release

Version 0.13.0 · September 2026

Four things arrive together: a waterfall that correlates spans with everything the JVM was doing, instrumentation libraries that trace your stack without rewriting it, analytics that search and rank spans by their attributes, and notifications & exceptions that put the application’s own story into the trace. All of it recorded as JFR events in the same file as the profiler’s samples — no collector, no exporter, no second agent.

Feature 01 · Waterfall

Jeffrey Traces Ready to use

One unit of work becomes a tree of timed spans recorded as JFR events in the same recording as the profiler’s samples — and the waterfall correlates that tree with CPU samples, SQL statements, socket reads, lock waits, GC pauses and safepoints.

Self-versus-child time on every bar, the critical path kept bright, repeated siblings folded into runs with P95 and mini-histograms, overlays for GC, safepoints, blocking spans, exceptions and notifications — and behind every span, a flamegraph and a Why slow ranking.

Feature 02 · Libraries

Instrument Without Rewriting Code

The jeffrey-tracing libraries: a zero-dependency Tracer API of eleven methods, modules for Servlet, Spring, JDBC, HikariCP, MyBatis and gRPC, and a Spring Boot starter that auto-configures the lot — add the dependency and write nothing.

Or mark a method @Traced: the Jeffrey Agent weaves the span at class load, the method is left exactly as written, and argument capture is opt-in, allow-listed to stable value types. Any JFR event declaring a spanId field is a span source — custom events participate with zero configuration.

Feature 03 · Analytics

Trace Analytics

Search Traces ANDs attribute conditions with same-span or anywhere-in-trace matching and compares the matches’ latency against the whole profile. Attribute Values ranks every value of a key by total time rather than call count. Latency by Attributes draws each value over log-spaced duration buckets — percentiles hide bimodality; the heatmap shows it.

Notifications are searchable the same way, and a search result opens the waterfall in place.

Feature 04 · Moments

Notifications & Exceptions

jeffrey.Notification lets the application write a moment into its own recording — a threshold crossed, a cache warmed, a circuit breaker opened — stamped with the enclosing span’s ids so it lands in the right place in the waterfall. Kind and message stay low-cardinality and dictionary-pooled; per-occurrence detail goes into searchable attributes.

Exceptions need no instrumentation at all: every throw in the recording is attributed to the span that was running, stack trace folded into the same docked panel notifications use.

Improvements

Microscope

Profile Databases, Dramatically Smaller

The same SQL text used to be stored per-row four times over — a 92 MB recording could produce a multi-gigabyte profile database. Repeated texts are now dictionary-pooled and events became a view, so every existing reader is unaffected while the database shrinks by orders of magnitude.

Trace Export for AI Assistants

The waterfall and the operation drill-down export what you are looking at as a single Markdown document built for pasting into an AI assistant — opening with a how-to-read preamble so span semantics aren’t guessed wrong.

Flamegraphs Fail Loudly

A failed flamegraph request now surfaces the error instead of spinning forever — and the weight extractor skips events that carry no class instead of producing a broken entity.

Instance Timeline, Tidier

The per-instance timeline card folds its meta strip into the card header — the same information, one visual unit per instance.

Hub & Provisioner

A Provisioned JVM Records What Traces Need

The stock JFR configuration keeps lock waits above 20 ms and socket I/O above 1 ms — coarser than a trace is read at. The provisioner now starts a second recording carrying only the lowered thresholds; JFR applies the most verbose setting, so the dumped files and the live stream both pick them up. TRACING=off opts out.

Environment Variables as a Real Config Layer

The provisioner merges the environment as a proper configuration layer instead of per-field fallbacks — and a settings-file ordering bug that could fail provisioning outright on real installs is fixed.

Platform

MyBatis Tracing by Default

Statements are named by their mapper method — far more readable than raw SQL — and record the bound parameter values. The interceptor takes over from the generic DataSource wrapper so nothing is double-recorded.

Jeffrey Tracing Documentation

Tracing is a first-class product on the docs site: 18 guide pages plus one page per Tracer API method, with the Jeffrey Events catalog and span trees drawn as real diagrams.

Claude Skills in the Box

Five skills ship with the libraries so an AI assistant can instrument a codebase correctly — core, gRPC, HTTP client, MyBatis and Spring REST server.

Streamed JDBC Row Counts

Streamed statements now report how many rows they actually delivered, so a query that returns nothing is distinguishable from one that floods.
